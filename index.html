Accessibility planning tool for meetings and events

Use this tool to create an accessibility planning path for your meeting or event.

This tool is for organizers, hosts, moderators, presenters, facilitators, and technical support staff.

Need detailed guidance? See the Best practices for accessible meetings and events (opens in a new tab) guide.

You can use the complete guide without completing this questionnaire.

The interactive questionnaire needs JavaScript. Use the complete guide, which is available without JavaScript.

Answer the three questions, then select Show my planning path. Questions 1 and 2 require an answer; additional session features in question 2 and quesion 3 are optional. You can edit your answers and rebuild the checklist at any time.

1.  How will participants attend? (required)

Choose how participants will attend.

2.  What are you planning?

Expected total audience size (required)

Choose the expected audience size.

Session features (optional)

Select all that apply. Leave them unchecked if none apply.
